# Quantity evidence is required before a replacement-import scenario

**Current state: the fixed UN Comtrade cohort fails its quantity/common-support gate. No development or later scenario was scored, no empirical allocation result is established, and this is not a released study.**

The complete corrected snapshot contains 140 original records from 49 fixed preview requests. Independent readers reconcile 10,799 original-field/native-token conditions, and a separate SQLite/Decimal/Fraction path checks 570 conditions and confirms the same gate failure. There are 127 positive native net weights, four zero values and nine JSON null values. Zero/null weights are unavailable observations, not confirmed zero trade.

Egypt's World-import net weights are unavailable in all three requested years. Its 2019 common-support quantities and required 2020 prior links are unavailable. Morocco's 2020 common-support share is 79.48%, below the fixed 80% minimum. These source failures cannot be averaged away by passing code tests, original-byte reconciliation or a plausible-looking allocation diagram. The original countries, years and numerical gates were not dropped or relaxed to obtain a scenario result.

The acquisition record retains an initial HTTP 429, the explicit provider wait and one slower continuation. The intended-France identifier was corrected to the publisher's customs-area code 251 after its documented distinction from geographic M49 code 250; all affected originals and the source exposure remain preserved. No account, key, paid request or quota bypass was used.

The exact flow implementation and independent cut oracle pass 36 finite tests, including sixteen small route patterns within one test. They are implementation evidence on authored fixtures, not a completed empirical trade study. The [protocol](PROTOCOL.md), [source binding](SOURCE_BINDING.md), native projection, complete exclusions and gate receipts remain inspectable. There is no manuscript, release tag, shortage probability, real spare-capacity estimate or measured financial benefit.

The originally proposed FAO source was checked only at metadata/schema level after the UN gate failed. It supplies compiled trade quantities and can use partner reports to fill gaps, so it would be a separate source basis rather than independent confirmation of UN's missing net weights. Its inspected matrix query/schema does not itself establish the complete national-total denominators, exact commodity/customs-area correspondence and bounded extraction needed here. Those definitions and rights would need a source-specific plan before any FAO cohort retrieval; none has occurred. The next source step is to establish those inputs for the same declared cohort, preserving this failed UN version and all fixed analytical gates.

Program execution continues with other studies. This source hold adds no completed study and does not alter the 31/50 released count. Separate formal-publication projects remain private.
