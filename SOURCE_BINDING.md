## France is a publisher customs-area code

The original M49-geographic France code 250 returned empty World-export envelopes. The official [reporting customs-area guide](https://uncomtrade.org/docs/reporter-country-codes-and-their-custom-areas/) explicitly says Comtrade does not use geographic France 250; its France reporting area is 251, including Monaco and the applicable overseas departments. The same guide distinguishes USA customs area 842 from geographic M49 840. These customs-area definitions, not geographic-country-only coverage, are retained.

Before source qualification, any source weights were summarized, or any scenario ran, the intended-France binding was corrected to 251. The exact 49-request manifest changes thirteen URLs; unchanged original successful captures are inherited byte-for-byte, and the affected originals remain preserved separately. Country identities were not selected on scenario performance, no cohort member/year was dropped, and no numerical gate changed. Empty code-250 envelopes are unavailable identifier results, not zero French exports. The initial identifier failure and one targeted correction are disclosed; no untouched-identifier claim is made.
