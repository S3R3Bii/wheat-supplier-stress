# Check shared capacity before promising replacement imports

Three importers cannot each claim the same supplier's extra volume. This study will compare separate-country replacement calculations with a jointly feasible wheat-import network, using reported trade links and explicitly authored capacity assumptions.

**Current state: protocol before trade-data retrieval.** No shortage probability, real spare capacity, economic saving or live policy recommendation is established. [The protocol](PROTOCOL.md) fixes the cohort, quantity checks, shared-resource scenarios and independent optimality checks. Source metadata and redistribution terms have been inspected; no cohort trade values or scenario scores have been retrieved.
